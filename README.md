# NLP-Lab-Programs

A collection of **32 Natural Language Processing (NLP) programs** implemented in Python as part of the NLP laboratory coursework. The programs cover text preprocessing, feature extraction, machine learning, deep learning, and transformer-based NLP applications.

## Repository Structure

```text
NLP-Lab-Programs/
├── CO1/    # Programs 1–6: NLP Fundamentals
├── CO2/    # Programs 7–23: NLP Techniques and Models
├── CO3/    # Programs 24–32: Advanced NLP Applications
└── README.md
```

## Requirements

- Python 3
- Google Colab or Jupyter Notebook
- Required Python libraries: NLTK, spaCy, scikit-learn, NumPy, Gensim, Transformers, PyTorch, and other program-specific dependencies.

## How to Run

1. Open the required program in Google Colab or Jupyter Notebook.
2. Install the libraries mentioned in the program.
3. Run the code and observe the output.

## Learning Outcomes

- Understand NLP preprocessing and text representation.
- Apply statistical and machine learning techniques to text.
- Explore deep learning and transformer-based models.
- Implement practical NLP applications.
